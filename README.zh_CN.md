# Linux Basics for Hackers - 学习笔记

基于 *Linux Basics for Hackers* 一书(作者 OccupyTheWeb)整理的结构化学习笔记。最初在 Obsidian 中通过个人实验环境积累,然后借助 AI 辅助进行了结构化整理,以提升清晰度、一致性和易用性。

> **更新说明:** 核心模块已新增可视化架构示意图,用于展示文件系统树、命令流水线、权限以及内核空间等概念。

> 本文档为 README.md 的简体中文翻译版本
